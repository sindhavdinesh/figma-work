## 📌 About This Project

**MORENT** is a modern, premium car rental web application built from a professional **Figma design**. It provides a seamless and visually stunning experience for users looking to rent their dream car — safely, reliably, and at low prices.

This project demonstrates pixel-perfect **Figma to Code** conversion with clean code, smooth animations, and a fully responsive layout.

---

## ⚡ Features

✅ Pixel-perfect **Figma to HTML/CSS** conversion  
✅ **Responsive design** — works on Desktop, Tablet & Mobile  
✅ Beautiful **gradient hero banners** with CTA  
✅ **Pick-up & Drop-off** booking system with Location, Date & Time  
✅ **Swap button** to switch pick-up/drop-off in one click  
✅ **Popular Cars** — horizontal scrollable section  
✅ **Recommended Cars** — 8 card responsive grid layout  
✅ **Favorite/Wishlist** toggle with heart animation ❤️  
✅ **Search bar** with filter functionality  
✅ **Notification badge** system  
✅ **Smooth hover effects** and micro-animations  
✅ **Show More** button with car count badge  
✅ Clean & professional **footer** with About, Community & Socials
