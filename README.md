## 🎯 About The Project

**MORENT** is a modern, premium car rental web application that provides a seamless and visually stunning experience for users looking to rent their dream car. Built from a professional **Figma design**, this project showcases pixel-perfect UI implementation with smooth interactions and responsive design.

> *"Ease of doing a car rental safely and reliably. Of course at a low price."*
